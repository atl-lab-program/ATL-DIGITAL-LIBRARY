To read Excel files (.xlsx or .csv) in PHP without overcomplicating things, use PhpSpreadsheet (the industry standard) or parse CSVs natively using fgetcsv().

Install via Composer: composer require phpoffice/phpspreadsheet

Parse the uploaded file to extract column headers and rows:

PHP
require 'vendor/autoload.php';

use PhpOffice\PhpSpreadsheet\IOFactory;

function getExcelData($filePath) {
    $spreadsheet = IOFactory::load($filePath);
    $sheet = $spreadsheet->getActiveSheet();
    $rows = $sheet->toArray(null, true, true, true);
    
    // First row as headers (Columns A, B, C...)
    $headers = array_shift($rows); 
    
    return [
        'headers' => $headers,
        'data' => $rows
    ];
}

Phase 4: Bulk Generation & Image Rendering (PHP GD / TCPDF)
To handle generating 30 to 45 (or even hundreds of) certificates at once efficiently, your backend needs to loop through the Excel rows and stamp text onto the base image.

PHP has a built-in image processing library called GD, which is lightweight and perfect for stamping text onto PNG/JPEG templates. Alternatively, use TCPDF or FPDF if you prefer generating PDFs.

Here is how you handle bulk generation using PHP GD Library:

PHP
// generate.php
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $templatePath = $_POST['template_path']; // Path to base image
    $excelFile = $_POST['excel_path'];
    $mappings = json_decode($_POST['mappings'], true); // JSON from frontend
    
    // Load Excel data
    $excelData = getExcelData($excelFile);
    $rows = $excelData['data'];
    
    $generatedFiles = [];
    $outputDir = 'generated/';

    foreach ($rows as $index => $row) {
        // Load base image
        $image = imagecreatefromjpeg($templatePath); // or imagecreatefrompng
        
        // Define text color (RGB)
        $black = imagecolorallocate($image, 0, 0, 0);
        
        foreach ($mappings as $field) {
            $colKey = $field['column']; // e.g., 'A'
            $textToPrint = $row[$colKey] ?? '';
            
            $x = $field['x'];
            $y = $field['y'];
            $fontSize = $field['size'];
            
            // Note: GD uses built-in fonts or TrueType fonts (.ttf) via imagettftext
            $fontFile = __DIR__ . '/fonts/Arial.ttf'; 
            
            imagettftext($image, $fontSize, 0, $x, $y, $black, $fontFile, $textToPrint);
        }
        
        // Save individual certificate
        $fileName = 'certificate_' . ($index + 1) . '.jpg';
        $savePath = $outputDir . $fileName;
        imagejpeg($image, $savePath);
        imagedestroy($image);
        
        $generatedFiles[] = $savePath;
    }
    
    // Zip them all up for bulk download
    $zip = new ZipArchive();
    $zipName = 'certificates_' . time() . '.zip';
    if ($zip->open($outputDir . $zipName, ZipArchive::CREATE) === TRUE) {
        foreach ($generatedFiles as $file) {
            $zip->addFile($file, basename($file));
        }
        $zip->close();
    }
    
    // Return download link for the ZIP archive
    echo json_encode(['status' => 'success', 'download_zip' => $outputDir . $zipName]);
}

This script processes the mapping configuration, loops through all rows in your CSV file (handling 30 to 45+ certificates instantly), stamps the text onto the image using PHP GD, zips them up, and outputs a download button.

<?php
if ($_SERVER['REQUEST_METHOD'] !== 'POST') {

$sizes = $_POST['size'];

if (($handle = fopen($csvPath, "r")) !== FALSE) {
    $headerRow = fgetcsv($handle, 1000, ","); // Skip header
    while (($data = fgetcsv($handle, 1000, ",")) !== FALSE) {
        $rows[] = $data;
    }
    fclose($handle);
}

$generatedFiles = [];
$outputDir = 'generated/';
if (!is_dir($outputDir)) {
    mkdir($outputDir, 0777, true);
}

// Loop through each row to create a certificate
foreach ($rows as $index => $row) {
    // Load image based on extension
    $ext = strtolower(pathinfo($imagePath, PATHINFO_EXTENSION));
    if ($ext === 'png') {
        $image = imagecreatefrompng($imagePath);
    } else {
        $image = imagecreatefromjpeg($imagePath);
    }

    $black = imagecolorallocate($image, 0, 0, 0);

    // Apply each mapped field onto the certificate
    for ($i = 0; $i < count($columns); $i++) {
        $colIndex = $columns[$i];

        $x = (int)$xCoords[$i];

        $zip->addFile($file, basename($file));
